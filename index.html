📖 Cours Complet : Le Système MGRS

Le MGRS (Military Grid Reference System) est le standard géographique de l'OTAN. Il fonctionne en mètres pour mesurer des distances directement sur le terrain.

1. Décomposition d'une coordonnée

Exemple type : 31U DQ 4825 1290 (se lit strictement de gauche à droite)

  • Le Fuseau (ex: 31U) : Grande zone géographique de base. La France métropolitaine est principalement sur les fuseaux 31T, 31U, 30T ou 32T.
  • Le Carré de 100 km (ex: DQ) : Désigné par deux lettres, il repère le grand secteur sur la carte d'état-major.
  • La Coordonnée Métrique (ex: 4825 1290) : Nombre pair de chiffres.
    👉 Règle d'or : "On lit d'abord l'avenue (axe horizontal / vers l'Est), puis on monte dans l'immeuble (axe vertical / vers le Nord)."

2. Les Niveaux de Précision

Chiffres Précision Usage
2 chiffres (48 12) 10 kilomètres Vaste région / secteur global
4 chiffres (482 129) 1 kilomètre Carré de base de la carte IGN
6 chiffres (4825 1290) 100 mètres Standard tactique (ralliement, obstacle)
8 chiffres (48256 12903) 10 mètres Position GPS précise (bâtiment)

3. Méthode pour trouver un point (à 6 chiffres)

Pour le point DQ 482 129 :

  1. Repérer le carré de 100 km DQ sur la carte.
  2. Chercher la ligne horizontale vers l'Est correspondant aux 3 premiers chiffres (482).
  3. Chercher la ligne verticale vers le Nord correspondant aux 3 chiffres suivants (129).
  4. L'intersection donne le coin inférieur gauche du carré de 100m.
